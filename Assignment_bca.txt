I would make the assignment code-oriented, but ensure that all four units are represented. Each team gets a different problem statement, and students should implement it using Python + appropriate ML libraries, explain the algorithm, show output, and give a short conclusion.
BCA Semester V – Machine Learning
Group Assignment – 24 Teams
Total Students: 48 Team Size: 2 students Total Teams: 24 Teams: 1–24
General instructions for every team
Each team should:
	1.	Understand the given problem.
	2.	Find/create a suitable dataset.
	3.	Implement the solution using Python.
	4.	Use appropriate libraries such as NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
	5.	Display suitable results/graphs.
	6.	Explain the algorithm used.
	7.	Submit:
	•	Python source code
	•	Dataset
	•	Short report
	•	Output/screenshots
	8.	Each team member should be able to explain the complete program during evaluation.

One important suggestion
I would not make every team use the same dataset. Give them the problem statement, but allow them to find an appropriate dataset from sources such as Kaggle/UCI or create a small dataset where appropriate. This will make the assignments genuinely different and reduce copying.
For the more mathematical topics such as MLE, Bias/Variance, Loss/Risk and Influence Diagrams, keep the datasets small and the programs simple. The goal should be that both students understand the concept and can explain their code, rather than simply downloading a large project from GitHub.
